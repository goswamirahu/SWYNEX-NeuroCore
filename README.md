
# SWYNEX-NeuroCore

## Project Overview
SWYNEX-NeuroCore is a Java-based educational neural network simulator.
It demonstrates basic neuron calculations and activation functions.

## Features
- Neuron calculation using weights and bias
- Sigmoid activation function
- ReLU activation function
- Neural network prediction
- Object-oriented Java design

## OOP Concepts
- Encapsulation: Private fields in the Neuron class
- Abstraction: Abstract ActivationFunction class
- Inheritance: SigmoidFunction and ReLUFunction extend ActivationFunction
- Polymorphism: Different implementations of activate()

## Technologies
- Java
- IntelliJ IDEA

## How to Run
Open the project in IntelliJ IDEA and run Main.java.

## Note
This is an educational simulator, not a trained AI model.
